# little by little

헤이링 학습 내용을 기록하고 영어 표현을 매일 복습하는 개인용 웹입니다.

## 서버 월요금 없는 배포

**Cloudflare Workers Free + Static Assets + D1** 구성을 추가했습니다. 웹 화면과 API를 같은 `workers.dev` 주소에서 제공하므로 PC를 켜둘 필요가 없고, 기존 Porkbun 도메인을 변경하지 않고 시작할 수 있습니다. GitHub에는 코드만 보관합니다.

- 서버/DB: Free 플랜 한도 안에서 사용. 유료 전환·결제 등록은 코드가 수행하지 않습니다.
- OpenAI: 버튼으로 실행한 AI 정리에 별도 API 사용료 발생.
- 비밀번호: salt + 서버 비밀값을 적용한 PBKDF2 해시. 평문 저장 없음.
- 학습 기록: D1에 계정별 저장. 공개 GitHub에 저장하지 않음.
- 새 가입: 최초 운영자는 설정 코드 필요. 이후에는 24시간·1회용 초대 링크 필요.
- 공유: 직접 ‘함께 보기’로 지정한 기록만 연결된 친구에게 공개. 복습 진도는 개인별 유지.

배포 순서는 [무료 배포 안내](DEPLOY-FREE.md)를 참고하세요. **코드는 준비됐지만 Cloudflare 계정 연결과 실제 배포는 아직 완료하지 않았습니다.**

## 로컬 실행

Node.js 24 이상에서 `npm run dev` 실행 후 http://127.0.0.1:5173 에 접속합니다. 외부 패키지 설치 없이 실행됩니다. 로컬 버전은 `server.mjs`, `lib/social.mjs`와 `data/study.sqlite`를 사용합니다. 온라인 버전은 `cloudflare/worker.mjs`, `cloudflare/social.mjs`와 D1을 사용합니다.

기존 OpenAI 키는 `.env.local`의 `OPENAI_API_KEY`에 직접 입력합니다. 이 파일은 Git과 웹 공개 대상에서 제외됩니다. 온라인에서는 같은 키를 Cloudflare Secret으로 등록해야 합니다. `.env.local`을 업로드하지 마세요.

## 구현 범위

- 표현·학습 메모 저장, 검색, 복습 일정, 목표, JSON 내보내기
- 아이디/비밀번호 로그인, 초대, 공유, 계정별 저장, 저장 충돌 감지
- OpenAI Responses API로 학습 메모에서 최대 5개 표현 추출
- 브라우저 제공 음성 읽기 및 음성 인식
- 기기 메모리에서 최대 60초 녹음, 재생/다운로드 (서버 업로드 없음)

AI 음성 생성, 자동 발음 평가, 실시간 AI 대화, 사이트 밖 알림, 계정 삭제/비밀번호 재설정은 아직 구현되지 않았습니다. 현재 음성 읽기는 브라우저 TTS이며 녹음 기능을 발음 평가로 표시하지 않습니다.

## 한도 및 개인정보

온라인 개인 공부방은 최대 20계정, 계정별 기록 500KB·표현 2,000개·메모 200개·복습 이력 10,000개입니다. AI 정리는 계정별 하루 30회, 전체 하루 100회, 계정별 5초 구간당 1회까지 시도할 수 있습니다. 실패한 시도도 한도에 포함하며 날짜 기준은 UTC입니다. 이 횟수 제한은 OpenAI 월간 금액 한도가 아닙니다.

D1/Workers 무료 한도에 도달하면 요청이 실패할 수 있습니다. 유료 계정의 과금 정책을 코드로 Free로 바꿀 수 없으므로 배포 전에 **Workers Free**인지 확인해야 합니다. 레코드는 주기적으로 파일로 백업하세요.

초대 링크는 URL fragment를 사용하며 진입 후 주소창에서 지웁니다. 새로고침으로 초대 정보가 사라졌으면 원래 링크를 다시 여세요. 연결 해제는 이후 공유 접근을 차단하지만 친구가 이미 가져온 사본은 지우지 않습니다.

## 검증

`npm run check` / `npm test` / `WORKER_ASSETS=1 npm run build:pages`

테스트는 실제 SQLite를 D1 인터페이스로 감싼 어댑터로 SQL·격리·초대·인증·할당량을 확인합니다. Cloudflare 실제 런타임의 CPU 한도, 브라우저 쿠키, 마이크 및 실제 OpenAI 호출은 배포 후 별도 확인이 필요합니다. 테스트는 실제 OpenAI를 호출하지 않습니다.

GitHub Pages 전용 빌드도 유지됩니다. `npm run build:pages`는 API 주소가 없으면 로그인 기능을 비활성화한 로컬 기록 전용 화면을 만듭니다. 분리 배포 시 `PUBLIC_API_BASE`에 HTTPS API 주소가 필요하며 두 주소의 쿠키 조건도 맞아야 합니다. 기본 권장은 같은 Workers 주소에서 화면과 API를 제공하는 방식입니다.
